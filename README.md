# ДКР. Конфигурационный язык → JSON

Комаров В.Ю., ИКБО-41-25, вариант 8.

Программа читает конфигурацию из стандартного ввода и печатает JSON.
Синтаксис описан в `src/language.lark`, разбор делает Lark.
При ошибке программа пишет сообщение в stderr и возвращает код 1.
Синтаксические ошибки сопровождаются номером строки и столбца.

## Запуск

Нужен Python 3.10+. Отдельной сборки нет.

```bash
python -m pip install -r requirements.txt
python -X utf8 src/main.py < examples/audio.cfg
python -m unittest discover -s tests -v
```

Перенаправление `<` работает в Bash и CMD. В PowerShell можно
использовать `Get-Content -Raw examples/audio.cfg | python -X utf8 src/main.py`.

## Синтаксис

- `;` начинает комментарий до конца строки, `{ ... }` — до закрывающей скобки.
- Числа требуют точку, например `12.` или `12.5`.
- В `#(1., #(2., 3.))` второй элемент сам массив. `#()` — пустой массив.
- `const base = 4.` задаёт константу. Имена состоят из букв `a-z`.
- `$base 1 +$` даёт `5.0`. Операции `+`, `-`, `*` и `pow()`
  берут два последних числа со стека. Например, `$2 3 pow()$` даёт `8.0`.
  Целые числа без точки допустимы внутри выражений, как в методичке.
  Константа должна быть объявлена до использования.

В JSON попадают значения, объявленные отдельно от `const`.
Одно значение выводится как есть, несколько — как массив, а если
есть только объявления или комментарии, выводится `[]`.

## Примеры

- [Звук](examples/audio.cfg) → `[48000.0, 1024.0, [0.8, 0.75]]`
- [Теплица](examples/greenhouse.cfg) → `[[21.5, 25.5], [45.0, 65.0]]`
- [Хранилище](examples/storage.cfg) → `[1024.0, 131072.0, 112.0]`

Тесты проверяют вложенность, операции и ошибки, а также запускают
все три примера через stdin. Работа сохранена в трёх коммитах.
